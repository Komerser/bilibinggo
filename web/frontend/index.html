      LLM 配置

      解析转发抽奖动态正文，提取奖品与开奖时间。互动 / 预约抽奖不消耗 LLM，推荐使用 DeepSeek-V4-Flash。

      API 方案使用顺序

      从上到下使用。服务商返回余额或额度用尽时，自动重试下一套方案。

      当前由 LLM 环境变量指定接口。取消环境变量覆盖后，即可使用下方顺序。

        必填

        服务商密钥，保存后仅显示首尾各 4 位，不会明文展示。

        选填

        新增方案时，留空使用默认接口。

        必填

        文本模型标识，例如 DeepSeek-V4-Flash。

        Open Source · Community Fork

        bilibinggo · Komerser fork

        检索并复核抽奖线索，增量导入活动；通过统一队列执行更新、检索与自动顺序参与，在本地查看历史、任务日志与用量统计。

        • 唯一新视频检索 按目标收集新 BV，跨页去重，停止后可继续
        • 统一任务队列 更新、检索与参与依次执行，日志汇总进度与结果
        • 自动顺序参与 按筛选与排序逐项参与，执行前检查活动条件
        • 请求与模型用量 概览查看平台请求、模型用量与近期记录
        • 本机私有数据 活动与历史存入 SQLite，Cookie 与密钥留在本机
        • Windows 发行包 提供 x64 安装包与便携包，其他平台可参考源码
